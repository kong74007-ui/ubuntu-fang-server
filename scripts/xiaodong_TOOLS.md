## 🎯 抖音评论区获客引擎（核心杀手锏）

群友想要"精准客户名单"时，我**不是给建议，而是真去抖音爬**。

### 关键词获客（最常用）
群友说「爬一下 XX 的客户 / 找 XX 的精准客户 / XX 这个词有哪些潜在客户」时：

```bash
python3 /home/ubuntu/leadgen-server/leadgen.py "关键词" --count 10
```

- `关键词`：行业词，如「瘦脸」「美容院拓客」「皮肤管理」「医美」
- `--count`：要爬的视频数，默认 10（越大越久；10 个视频约 1-3 分钟，能出 20-40 个客户）
- 输出：精准客户名单（昵称 / 抖音号 / 属地 / **需求原话** / 主页链接）+ 自动发现的高潜词
- 引擎已自动剔除同行中介的广告，只留真实有需求的人

### 账号深扒（对标分析）
群友贴**抖音主页链接**说「扒一下这个账号 / 分析这个对标号」时：

```bash
python3 /home/ubuntu/leadgen-server/leadgen.py "主页链接" --mode account
```
- 输出账号画像 + 全部作品 + 评论；结果生成 xlsx，可在网页或飞书取

### 我该怎么把结果发群里
- 命令会等爬完才返回（1-3 分钟），**爬取期间先回一句**「收到，正在抖音上扒『XX』的精准客户，约2分钟，扒完发你」让群友别干等
- 拿到名单后，**挑重点整理成飞书消息**：客户昵称 + 需求原话 + 主页链接，别一股脑全贴
- 名单较长时只发前 10-15 个，并说明"共 N 个，完整名单可在网页查/导出"

### ⚠️ 注意
- 实际爬取在 Tang 的 Mac（住宅IP）上执行，**Mac 要开机联网**才能爬；若命令报「任务未完成/登录态失效」，说明抖音账号 cookie 过期了，提醒 Tang「重新扫码」
- 这是公司内部获客工具，只对自己人用；爬出来的是公开评论，用于正当商业触达
