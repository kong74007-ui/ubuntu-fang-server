## 一、竞品画廊规模与结构（事实观察）
- **规模**：灵感画廊约 **391 张样片**，**24 个分类**——内容很满、很多。
- **页面结构**：左 88px 图标导航（灵感/视频/作图/编导/音频/画布/资产/AI工具）+ 顶部促销 banner + 「灵感案例/教程视频」切换 + 分类筛选 chip + **masonry 瀑布流**。
- **每张卡**：一张图或视频缩略 + 标题 + 点赞数 + 悬停「**做同款**」（带入该样片的提示词/参数到对应工具）。

## 四、逐步填满计划（全用黄雀自有内容）
**第 1 步（现在·手头素材）**：把现有 13 张 + `generated_layers/` 3 张大图原作 + `meiye_video` 首帧补进画廊，分类扩到 8–10 类，先把网格铺满到 ~20 张。

**第 2 步（gpt-image-2 渠道恢复后·批量生成）**：每个分类批量生成 **5–10 张黄雀样片**（美业海报/数字人/节日/电商/LOGO/国风…），**配我们自己写的「做同款」提示词** → 目标先填到 **50–80 张**，达到"内容很满"的观感。

**第 3 步（视频样片）**：用 `meiye_video` + Seedance 生成的口播视频做「视频/数字人」分类的样片卡。

**第 4 步（做同款打通）**：每卡的「做同款」带入我们原创提示词 → 点击进作图/视频工作台并预填，形成"看到→一键同款→出图"的闭环。

## 五、原则
- 竞品的图、提示词一张/一句都不搬；只学它的**分类体系、内容密度、做同款机制**。
