# AI Edit V2 素材边界与临时播放地址设计

## 目标

修复测试站 AI Edit V2 的两个真实问题：剪辑任务会自动拿用户历史口播作为补充素材；资产页停留超过五分钟后，预览和下载继续复用已经过期的私有 COS 地址。

## 素材来源边界

第一版只允许以下来源：

1. 用户在当前剪辑任务中上传的补充素材。
2. 当前任务没有可用补充素材时，由 GPT 图片模型生成的图片。

明确禁止：

- 自动搜索或使用用户历史素材。
- 自动使用其他任务的主体口播视频。
- 使用尚未建设的平台公共素材库。
- 生成 AI 短视频素材。

主体视频只作为本任务主画面，不进入补充素材候选池。用户当前上传的“必须使用”素材继续执行现有强约束；普通补充素材经过格式、归属、任务范围、比例、清晰度和显式相关性检查后才能使用。

同一个普通素材默认只能填充一个导演素材槽位。若后续槽位没有其他合格的当前任务素材，则调用 GPT 生图；不能用同一无关素材填满多个语义不同的槽位。必须使用素材仍按现有协议保证至少被使用一次。

## 私有播放地址

数据库继续只保存私有 COS 对象键，不保存长期或永久公开地址。资产列表接口继续返回五分钟有效的签名 URL。

对于 `ai_edit_v2` 资产：

- 用户点击“放大预览”时，前端以 `cache: no-store` 重新读取已登录的资产接口，按资产 ID 取得新签名后再打开播放器。
- 用户点击“下载”时执行同样刷新，再开始下载。
- 刷新失败、资产不存在或返回空 URL 时，不复用旧地址，显示可操作的失败提示。
- 旧视频资产保持当前行为，不增加额外请求。

## 安全和兼容性

- 资产刷新沿用现有 Bearer Token 和账号归属校验。
- 不把 COS Secret、对象键或永久 URL暴露给前端。
- 不修改旧剪辑、旧视频生成、计费、Shotstack、BGM、音效和质检流程。
- 已完成资产无需数据库迁移。

## 验收标准

- 没有本次上传素材时，每个需要素材的槽位调用 GPT 图片生成，而不是读取历史口播。
- `user_history` 和 `platform_public` 不再被素材解析器查询。
- 同一普通当前任务素材不会自动占用多个素材槽位。
- 页面停留超过五分钟后，预览和下载仍能通过点击刷新正常工作。
- 刷新失败时不尝试过期 URL。
- AI Edit V2 全套测试、Python/JavaScript 语法检查和静态页面测试通过。
- 仅部署测试环境，生产环境不变。
