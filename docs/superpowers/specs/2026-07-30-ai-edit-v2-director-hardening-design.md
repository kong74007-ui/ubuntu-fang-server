# AI Edit V2 导演结构加固设计

## 背景

真实 `qwen-plus` 测试连续返回可解析 JSON，但首轮将 `style_system` 返回为非对象，后续修复又把 `scenes[0].id` 置空。任务最终报 `director_schema_invalid`，且失败任务的 `directing` 明细仍停留在 `running`。

## 设计

1. 输出契约补充字段类型、枚举、非空要求和完整合法示例，降低模型首次偏离概率。
2. 在严格 Schema 校验前只标准化无创意含义的结构字段：合法组件族字符串包装成 `style_system` 对象；空场景 ID 按顺序生成 `scene_01`。其余语义字段继续严格拒绝，不放宽协议。
3. 修复提示要求保留所有未报错字段，只修正字段级错误。
4. `DirectorError` 携带经过脱敏和截断的 Schema 错误路径，不保存模型原文。
5. 稳定流水线失败时将当前阶段尝试更新为 `failed`，在 `output_summary_json` 保存安全错误详情，再进入既有退款终态。

## 验收

- 真实失败形态可在本地回归测试中通过结构标准化。
- 非法语义、未知枚举和额外字段仍被拒绝。
- 最终 Schema 失败可读取安全字段路径，且阶段尝试不再残留 `running`。
- 导演、Schema、流水线、Runtime 与端到端测试全部通过。
