# AI Edit V2 平台口播懒加载设计

## 目标

用户在第一步切换账号内数字化 IP 口播视频时，只更新选中状态、封面、摘要和画面比例，不下载视频，也不执行平台素材导入。右侧预览区只有在用户点击播放后才加载当前视频；平台素材只在获取报价前解析为 V2 主体素材。

## 范围

- 仅调整“账号内数字化 IP 口播视频”的选择、预览和导入时机。
- 用户上传视频、上传音频、补充素材、模板、提示词、比例、计费和任务流程保持不变。
- 不修改后端接口和数据库结构，继续复用平台资产列表接口与导入接口。

## 交互设计

1. 点击平台口播卡片后立即完成选择，不显示“正在准备平台口播视频”，不调用导入接口。
2. 右侧预览区显示该资产的封面、居中播放按钮和“点击播放后加载视频”提示。
3. 初始预览 DOM 不包含带 `src` 的 `<video>` 元素。
4. 点击播放按钮后，才为当前选中资产创建播放器并设置视频 URL；播放器使用 `controls`、`playsinline` 和 `autoplay`。
5. 切换到另一条平台口播时，移除旧播放器及其 `src`，显示新封面。旧视频不得继续作为当前预览。
6. 同一条视频再次进入封面状态后，仍需重新点击播放才加载。

## 数据与状态

平台主体允许处于“已选择但尚未导入”状态：

- `platform_id`：服务端平台资产 ID。
- `preview_url`：仅在用户点击播放时使用。
- `thumbnail_url`：选择后立即用于右侧封面。
- `asset`：选择时为 `null`，报价前导入成功后写入 V2 material 信息。

切换主体时必须清除预览已激活状态。异步导入使用捕获的 `platform_id` 校验返回结果；如果用户在等待期间切换主体，旧结果不得覆盖新选择。

## 报价流程

“获取价格区间”在平台主体尚未导入时仍可点击。点击后：

1. 锁定当前选择并显示“正在准备平台口播视频”。
2. 调用现有 `/api/v2/edit/platform-assets/{id}/import`。
3. 仅当返回时当前选择仍为同一 `platform_id`，才写入 `state.main.asset`。
4. 使用解析后的主体构建 draft 并调用报价接口。
5. 导入或报价失败时显示错误，不创建任务、不扣点；用户可重试。

## 错误与降级

- 封面缺失或加载失败时显示统一占位背景和播放按钮，仍允许按需播放。
- 播放加载失败时在预览区显示错误和重试按钮，不影响重新选择其他主体。
- 平台素材导入失败时保留当前选择，报价按钮恢复可用。
- 用户未选择主体时，报价按钮继续禁用。

## 验收标准

- 连续切换至少三条平台口播，网络侧不请求其视频 URL，也不调用任何 `/import` 接口。
- 右侧点击播放后，只请求当前选中视频的 URL。
- 播放中切换主体后，右侧回到新封面；新视频不会自动加载。
- 尚未导入的平台主体仍可点击“获取价格区间”，导入成功后自动继续报价。
- 主体、剪辑方式和画面比例摘要保持同步；上传视频和上传音频入口仍存在。
- 全流程在获取报价前不扣点；测试不得提交创作任务。
